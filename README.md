# 🌸 بوت هيناتا V3 - النسخة العربية المترجمة بالكامل (Hinata Bot V3 Arabic)

أهلاً بك في النسخة العربية المترجمة الرسمية والجاهزة للتشغيل من **بوت هيناتا V3 (Hinata Bot V3)** لفيسبوك ماسنجر.
تمت ترجمة جميع النصوص والرسائل والملفات إلى اللغة العربية مع الحفاظ الكامل على كافة الوظائف والسرعة والأداء الأصلي للبوت دون أي تغيير في نظام التشغيل.

---

## 🌟 المميزات والخصائص

- 🇸🇦 **ترجمة عربية شاملة 100%**: جميع رسائل البوت، الأوامر، التنبيهات، وقائمة التعليمات أصبحت باللغة العربية.
- ⚡ **أداء عالي واستجابة سريعة**: مبني على بيئة Node.js مع دعم بروتوكول Mqtt و Facebook Messenger API.
- 🛡️ **نظام إدارة متطور**: إدارة المشرفين، الحظر، الإنذارات التلقائية (Warn system)، الأوامر المخصصة.
- 🤖 **دعم الذكاء الاصطناعي**: أوامر متعددة للذكاء الاصطناعي (GPT, Gemini, DeepSeek, Flux, DALL-E).
- 🎵 **تحميل الوسائط**: تحميل الفيديو والصوتيات من تيك توك، يوتيوب، فيسبوك، وبينتريست بنقرة واحدة.
- 💾 **قواعد بيانات متعددة**: يدعم SQLite و MongoDB و JSON لسهولة الحفظ والربط.

## 🚀 متطلبات التشغيل

1. **Node.js**: الإصدار 18 أو أعلى.
2. **Git**: لنقل وتحديث الملفات.
3. **حساب فيسبوك (أو كوكيز/Appstate)**: لتسجيل دخول البوت.

---

## 🛠️ خطوات التشغيل والتركيب

### 1. تثبيت المكتبات (Dependencies)
افتح موجه الأوامر (Terminal / CMD) في مجلد البوت واكتب:
```bash
npm install
```

### 2. إعداد ملف التهيئة (`config.json`)
قم بفتح ملف `config.json` وتأكد من الضبط الآتي:
- `language`: `"ar"` (مضبوط تلقائياً).
- `prefix`: `"!"` (أو البادئة التي تفضلها مثل `/` أو `.`).
- `adminBot`: أضف آيدي الفيسبوك الخاص بك في هذه القائمة لمنح نفسك صلاحيات المالك/الأدمن.

### 3. تسجيل الدخول ببيانات الحساب
يمكنك استخدام إحدى الطرق التالية:
- **نص الكوكيز (Cookie String)** أو **ملف AppState (fbstate.json)**: ضع الكوكيز في ملف `appstate.json` أو أدخله عند تشغيل البوت.
- **البريد الإلكتروني وكلمة المرور**: اضبط الإيميل وكلمة المرور في `config.json`.

### 4. بدء تشغيل البوت
تشغيل عادي:
```bash
npm start
```
أو:
```bash
node index.js
```

## 📂 هيكلة ملفات اللغة

- `languages/ar.lang`: يحتوي على جميع نصوص النظام والاتصال والإنذارات بالعربية.
- `languages/cmds/ar.js`: يحتوي على ترجمة الأوامر والشروحات والرسائل التفاعلية.
- `languages/events/ar.js`: يحتوي على ترجمة أحداث الترحيب والمغادرة والإنذارات.
